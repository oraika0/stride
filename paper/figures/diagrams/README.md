# Hand-drawn figures

Figures 1, 3, 4 and 5 are diagrams rather than plots. They live on one draw.io
file with a page each, named after the caption, so the page names are the
mapping and nothing else has to record it:

| Page in `paper_diagrams.drawio` | Figure |
| --- | --- |
| `Figure 1. System architecture` | 1 |
| `Figure 3. Interaction loop between STRIDE and the SDN environment with actor-critic training` | 3 |
| `Figure 4. Pair-masked link encoder` | 4 |
| `Figure 5. Single reverse step in the joint diffusion routing decoder` | 5 |

`exports/` holds the PDF, PNG and SVG of each that went into the manuscript.
There is no script here: draw.io exports them, one page at a time, under the
page name. Re-export a page after editing it and the filename already matches.

One file rather than four is deliberate. Three of the four diagrams reuse the
same boxes -- the encoder, the decoder and the SDN block all appear inside the
interaction loop -- and keeping them on one canvas is what keeps the line
weights, the palette and the type sizes the same across the set.
